# 合入、发行与导出检查 · 0.1.0

main 已面向读者，待审正文不能因会话结束自动合入。工作分支保存与公开合入是两项动作，依据已有任务授权分别处理。

## 合入前

检查目标单元与范围：结构/内链/资源/ID；受审提交可取回；编辑及真实交叉审；事实和承诺平台实测；拟同步语言；生成物新鲜度；公开文件无私有资料。已知关键错误不能用通用备注放行。局部试读明确范围，不能冒充全书完成。CI只读，无发行凭据；私有报告由维护者核对，CI不证明其实。

## 里程碑

选择已整合提交 C，版本 vYYYY.MM.N。私有 releases/<tag>/plan.json 保存目标、范围、C、说明、附件及 SHA-256、推荐入口意图。先完成可审阅文件，再按已有授权执行。无附件可以发布，不默认生成 PDF。

公开前核对账号、显式目标、标签指向 C、草稿、附件和说明；公开时先不提升 latest，核验后再按意图更新。receipt.json 记录实际远端结果。入口未核对成功前继续指向上一公开版本。

源、说明、附件或目标改变须回准备核对；同名同内容可继续，不同内容停止。超时先查远端，不能盲建第二份发行；已公开仅入口失败则只修入口。推荐版已前进时不自动用旧版覆盖。正式标签与附件固定，不 force、不覆盖上传。

## PDF

只有明确导出请求才生成，从指定 C 干净副本构建，版本/导出编号/日期经参数传入。默认本地交付。延后公开使用独立 pdf-<正文版本>-NN 导出版，标签仍指向 C，不抢正文 latest。下载核对后才更新书仓入口。

普通 PR 检查不携带发布凭据。机制测试只使用明确的虚构材料和登记测试仓；当前 origin 不是授权依据。
