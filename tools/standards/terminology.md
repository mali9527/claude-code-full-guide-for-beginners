# 通用术语基础 · 0.1.0

本表只提供解释方式，不能代替各产品实际行为；书内术语采用后写入本书术语表。

| 词 | 普通人的解释起点 | 必须按产品补充 |
|---|---|---|
| 终端 | 用文字输入指令的窗口 | 实际软件、打开方式、系统差异 |
| 路径 | 文件在电脑中的地址 | 实际位置、分隔符、权限 |
| 版本 | 为一份软件或内容状态起的标识 | 产品版与本书版分别标明 |
| 权限 | 某项操作被允许到什么范围 | 默认值、确认方式、适用界面 |
| 上下文 | 这次任务提供给模型的信息 | 实际限制与处理方式，不能通用推断 |
| 核验 | 用证据检查一个说法或步骤 | 来源确认、实测、试读分别记录 |

同名术语不代表同一功能。新词先登记，再在首次出现处即时解释；不要只让读者翻术语表。
