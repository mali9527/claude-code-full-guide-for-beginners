# 事实、审校与实测 · 0.1.0

## 一份事实，一处引用关系

facts.yaml 保存主张、适用产品/界面/版本/套餐/地区、来源、查阅时间、周期及当前结论。book.yaml 的 facts 列表关联内容单元；不维护 used_in 反向副本。文档确认写事实记录，实际操作写 operations 检查，两者不能替代。

联网使用内置 Web 搜索和页面读取；关键事实阅读原页面。来源优先官方，社区经验注明性质。未知、未测、失败、不适用分别表达，不根据历史发布、文件存在或 Git 提交推测核验成功。

## 例行复核

价格、额度、账号及地区条件默认 90 天；安装、首次启动、权限和撤销默认 180 天；稳定概念无固定期限。周期安排维护，不是正确性保证。官方变化、失败和读者阻断立即触发复核，不等到期。

到期显示待复核。非关键历史信息可注明日期与限制；承担“照做可完成”的关键路径若未知、失败或已知过时，须复核、修正或明确缩减承诺，不能仅补一句“可能过时”。

## 检查记录

完整报告位于私有 private/<work-id>/reviews/；公开 checks/ 仅留 FORMAT 允许的摘要。源稿先保存提交 C，再在另一文件写 source_commit=C 和 paths。正文不写 verified_commit/verified_on。受审提交必须可取回；重写提交后重新确认引用与内容。

editorial、facts、operations、trial 分开记录。公开 engine 如实填 claude、codex 或 human；author_engine 记录起草引擎。作者接受人工替代时 reason 写依据，不把同引擎换会话写成跨引擎。私有姓名、聊天、截图个人信息、私有报告路径不进公开摘要。

有效性结合 Git 差异、事实状态、前置、适用范围及日期。正文实质改变重新审校；明确的生成导航区除外。只写 checks 不使正文自我失效。脚本可以核对版本和字段，不能证明私有报告存在或实验发生，维护者合入前检查真实性。

## 最少影响范围

正文变化：编辑/事实表达，操作变化重测，译文待同步。
事实变化：引用单元、练习、教程及登记短文。
前置变化：学习路径及目录导航。
翻译变化：对应语言审读与输出。
图内容变化：语义和渲染；字体变化只检查版式，不重查全书价格。

匹配不到标签不等于无影响，保留“尚无法判断”。同一变化复用稳定 ID，不重复建立任务。

## 每个单元需要什么证据

书级 required_checks 是默认要求；书内纯概念或分水岭单元可以在唯一 book.yaml 配置中显式声明 required_checks: [editorial, facts]，操作单元继续要求 operations。不得为了让检查变绿移除实际操作所需证据。必需项不能用不适用绕过；非必需项可提供理由登记为 not_applicable。范围变化本身需要重新核对旧摘要的适用性。
