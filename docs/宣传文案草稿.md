### 推荐模板（以"完全不会编程能学吗"为例）

```
完全可以，但大多数教程不是写给这种情况的——它们默认你会一点点 pip、cd、git。

我最近自己写了一本叫《Claude Code 零基础入门指南》的中文书，目标读者就是你这样的情况：
不会编程、没用过终端、没碰过 AI 编程工具。

具体做法上有几个点我觉得对"真零基础"特别重要：

1. 从"怎么打开终端"开始讲。很多教程第一句就是"打开终端输入 xxx"——但读者根本不知道终端是什么、
   在哪里打开、输入完按回车会发生什么。这本书前 5 章颗粒度最细，每一步都给预期结果 + 失败兜底。

2. Mac 和 Windows 每一步都分开讲。Windows 用户不用靠猜命令对应版本是什么。

3. 每章开头一张思维导图（用 Mermaid 画的，GitHub 直接渲染）。进章前先看 30 秒导图，
   心里有个整体地图再读文字，理解速度会快很多。

4. 不只讲"怎么用"，还讲"为什么它会变糊涂"、"记忆怎么分层"、"什么时候该停下来"——
   这些是新手能不能稳定用起来的关键。

全书 27 章 + 9 附录，约 8 万字。免费开源（CC BY-NC-SA 4.0），在 GitHub 上。

仓库地址：github.com/mali9527/claude-code-full-guide-for-beginners

希望对你有用。有问题直接去提 Issue 就行。
```
