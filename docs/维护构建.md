# 本书维护与构建

使用 Python 3.9+，先按 tools/requirements.txt 安装固定依赖。源稿、顺序与来源先保存到工作分支。

本仓核验日期按作者时区 `Asia/Tokyo` 记录，GitHub Actions 使用同一 `TZ`。在其它时区复现日期检查时也使用这一设置，避免 UTC 尚未跨日而把当天记录误判成未来；真正晚于该时区当天的记录仍须拒绝。

## 本轮简体构建与检查

```sh
python tools/studio.py --root . build
python tools/studio.py --root . build --check
python tools/studio.py --root . check --publication --language zh-CN
```

第一条生成简体合订稿、导航和首页受管区；后两条检查生成物新鲜度及简体正式发行范围。源稿或适用规则变动时，先保存源提交，再写真实的 checks 记录，最后保存生成物。不要把当前提交写成它自身的核验来源。

作者于 2026-09-25 明确调整本轮验收：操作说明采用官方文档核对，不做真实电脑验收，修正明显问题后正式发布简体。故本书 required_checks 为 editorial、facts；34 项 operations 保留 unknown。此调整有明确范围，不代表实测已完成，也不改变其他书的要求。详细依据见[简体发行复核](2026-09-25简体发行复核.md)。

跨引擎审核仍是作者手动触发的可选步骤。结构、资源、事实、编辑和插图检查没有关闭；CI 按同一简体范围执行，不带发布凭据。

## 暂停的繁体流程

`book.yaml` 的 zh-TW 输出已关闭，本轮不运行 `--zh-tw` 或 `reading_extras.py`，也不把繁体纳入公开质量范围。`zh-TW/`、translations.yaml 与 .studio/reading-extras.json 保留上次预览的内容及来源；入口新增暂停发行说明。它们不表示本次简体发行的同步译本。

以后作者重新启用繁体时，再用已保存源提交转换，更新语言审读与图内文字记录。`reading_extras.py` 是本书繁体入口适配器，必须在重新启用并完成逐章转换后使用；不能独立运行来假定旧稿仍然新鲜。

## PDF 与工具快照

工具快照版本为 0.1.0；本轮只在本书标准中记录作者指定的发行范围，未修改系列公共默认规则。快照清单记录这些本书修订。

用户另行要求导出时，才用 `studio.py build --pdf --source <固定提交> --version <正文版本> --export-id 01` 创建 PDF，只读取已提交快照。本书适配包含 tools/pdf-layout.typ、图宽、代码折行、页码和固定提交的附件链接。依赖 Pandoc、Typst、mmdc 与 Chrome，可通过 STUDIO_MMDC、STUDIO_CHROME 指定已有路径。

输出及 export.json 保存在 build/pdf/ 下，本地导出不等于公开 Release。早前九月本地 PDF 曾采用 A5 与旧 Mermaid 大图页，本轮没有重新导出；未来需重新核对图片、分页与跳转。
