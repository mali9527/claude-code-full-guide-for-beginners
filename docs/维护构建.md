# 本书维护与构建

使用 Python 3.9+，先按 tools/requirements.txt 安装固定依赖。源稿、顺序与来源先保存到工作分支。

```sh
python tools/studio.py --root . build --zh-tw
python tools/reading_extras.py
python tools/studio.py --root . check
```

第一条生成简体合订稿、导航与逐章繁体；第二条从这些繁体生成阅读入口、合订稿与历史链接页，不改译文章节；第三条检查源稿与当前生成物。`reading_extras.py --check` 和 `studio.py --root . build --check --zh-tw` 可检查新鲜度。

繁体转换记录在 translations.yaml，默认 review 为 pending。改变品牌保护或人工转换补丁后应重新生成。语言审读、编辑复核（允许当前引擎）、双平台操作分别记录；跨引擎审核仅由作者手动触发，未触发不构成阻断项。正式公开前运行 `studio.py --root . check --publication`；当前待验项会阻止通过，不能删除门槛来制造成功。

源稿与元数据改动后，先提交源稿再生成繁体，最后另存生成物和公开摘要。不要将当前提交写成它自身的核验来源。

工具的系列快照版本是 0.1.0；reading_extras.py 是本书适配器，输出清单在 .studio/reading-extras.json。旧繁体地址映射由 legacy-reading-paths.yaml 保存，不重复列章节顺序。历史 PDF 不参与这条 Markdown 构建；用户另行要求导出时才创建新 PDF。

## 九月 PDF 导出

用户已启用按需 PDF。使用 `studio.py build --pdf --source <固定提交> --version v2026.09.1-rc.1 --export-id 01`，只读取已提交快照。本书 PDF 适配包含 tools/pdf-layout.typ、完整图宽、代码折行、页码和固定提交的附件链接，属于 0.1.0 工具快照上的单书修订。依赖 Pandoc、Typst、mmdc 与 Chrome；通过 STUDIO_MMDC、STUDIO_CHROME 指定已有路径。输出及 export.json 保存在 build/pdf/ 下，不把本地导出冒充公开 Release。

早前九月本地 PDF 曾采用 A5 正文与 49 张旧 Mermaid 大图页；这不是当前 42 张手绘插图版的导出结果。本轮交付 Markdown 阅读稿，没有重新生成 PDF。未来导出需从固定提交重新构建，并复核图片、分页与跳转。
