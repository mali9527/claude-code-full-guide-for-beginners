# 版本与核验说明

资料核对日期：2026-09-24。Claude Code 新模型示例基线：2.1.280 或更新版本。模型重点：Opus 5.5、Fable 5.1。主体针对 Mac 与 Windows；不同账户和部署方式可能有差异。

## 这轮完成了什么

本轮实际更新中文源稿，重新生成阅读目录、导航、合订稿与繁体转换稿。模型与价格、账号与安装、权限与撤销、隐私与记忆、扩展配置分别以官方资料核对；来源登记在 facts.yaml，正文关键处提供阅读链接。示意对话和界面不作为运行记录。

维护机可执行 Claude Code 2.1.281 的版本与帮助检查。Hook 示例的本地脚本测试记录另见示例目录。结构、路径和派生文件检查由本仓工具执行。

- 修订由 Codex 完成并做同引擎复核，尚缺另一实际引擎的交叉审校。
