# 附录 D：决策流程图

## 图 1：权限决策流程（遇到弹窗怎么选）

```
Claude 弹权限窗口 → 它要干什么？
                         │
         ┌───────────────┼───────────────┐
         ▼               ▼               ▼
     读取文件         改文件          跑命令
         │               │               │
     通常 Yes         看 diff       看命令
         │               │               │
     （敏感文       改的是我让      是高危命令吗?
      件例外）     它改的地方吗?    （rm, force push,
                        │           删表等）
                  ┌─────┴─────┐         │
                  ▼           ▼    ┌────┴────┐
                 是          否    ▼         ▼
                  │           │   是         否
              Y 接受       N 退回    │         │
                                 详细    安全就
                                 审一    Yes
                                 次再
                                 决定
```

**口诀**：
- 读文件 → 一般 Yes（除非是 `.env`、密钥文件）
- 改文件 → **永远看 diff**，多改了 No
- 跑命令 → **高危必退**（详见附录 G）

## 图 2：模型选择流程（任务来了用哪个）

```
新任务 → 问自己三个问题
  │
  │  ① 难度：需要深度推理吗？
  │     - 否（简单查询、翻译、重命名）→ Haiku
  │     - 是 → 继续
  │
  │  ② 规模：上下文超 200K 吗？
  │     - 是（整本书 / 几百文件）→ Opus (1M)
  │     - 否 → 继续
  │
  │  ③ 日常 vs 硬核
  │     - 日常（80% 场景）→ Sonnet（默认）
  │     - 复杂推理 / 难任务卡了 → Opus
```

**新手一句话**：**默认 Sonnet，卡住切 Opus，简单事用 Haiku**。

## 图 3：Ctx% 使用率应对流程

```
瞥一眼状态栏 → Ctx 百分比
     │
     ├── 0-50% → 继续
     ├── 50-75% → 准备整理（任务快完？先收尾；任务长远？/compact）
     ├── 75-90% → 立刻 /compact 或 /clear
     └── > 90% → 断崖，马上 /clear 或退出重启
```

## 图 4：卡住了怎么办（5 分钟原则）

```
第 1 次尝试失败 → 调整 prompt → 再试
                        │
                        ▼
                    第 2 次失败
                        │
              【5 分钟原则触发】
                        │
           ▼                        ▼
     手动 < 5 分钟            手动 > 20 分钟

       关掉 Claude，            继续用 AI 但
       自己做                    换方向：
                              - /rewind 重开
                              - /compact
                              - 换模型
                              - /plan
                              - 拆小任务
```

## 图 5：信息分层决策（放哪一层记忆）

```
这条信息...
    │
    ├── 一次性的 → 会话里说就行（不存）
    ├── 跨项目 + 关于"我"的 → MEMORY.md
    ├── 项目规则 + 团队共享 → CLAUDE.md
    ├── 结构化任务流程（偶尔用） → Skill
    └── 外部长文档已存在 → Pointer（CLAUDE.md 里写"详见 XXX"）
```

## 图 6：扩展机制选型

```
我想要让 Claude ...
    │
    ├── 知道项目背景（每次都要）→ CLAUDE.md
    ├── 会做某类任务（偶尔用） → Skill
    ├── 让我敲 /xxx 一键触发     → Custom Command
    ├── 派独立专员干重活         → Subagent
    ├── 某事件自动触发动作       → Hook
    └── 连接外部系统              → MCP
```
