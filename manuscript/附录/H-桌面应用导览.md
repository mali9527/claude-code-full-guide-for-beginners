# 附录 H：Claude Code 桌面应用简明导览

> **说明**：本书主讲终端版 Claude Code。如果你嫌终端麻烦——**桌面应用**（2026-04 大改版）是同一引擎的图形版本，核心能力完全通用。这份导览让你快速对号入座。

---

## 什么时候切桌面应用值

- **看多会话不方便**（终端只能一个窗口一个会话）
- **大型 diff 审核**（图形化的 diff 比终端强多了）
- **需要 git worktree 并行工作**（桌面应用原生支持）
- **截图 / 图片输入频繁**（图形界面拖拽更顺）
- **对纯终端有抵触** 但想要 Claude Code 能力

## 什么时候终端版更好

- **追求极简**（终端最快）
- **远程服务器 / ssh** 场景（桌面应用只在本机跑）
- **深度定制 hooks / pipe**
- **脚本化 / CI 集成**（非交互模式）

---

## 桌面应用的五大界面元素

### 1. 多会话侧栏

左侧列表——**每个会话独立 Ctx**。

好处：
- 给不同项目 / 任务开**多个会话**，互不干扰
- 切换只需点一下，不用 `/exit` + `cd` + `claude`
- 每个会话显示模型 / Ctx% / 名字

### 2. 可视化 diff

Claude 要改文件时——**左右两栏图形化 diff**，不是终端的 ASCII 版本。

好处：
- **颜色清晰**（删除红底、新增绿底）
- **行号对齐**
- **接受 / 拒绝按钮**直接点（不用 y/n）

### 3. 内嵌终端

应用里**内建一个终端**，随时切。

好处：
- 不用开第二个 app
- 终端命令输出也在同一窗口，方便对照

### 4. 拖拽面板 / 文件浏览器

左侧有 workspace 文件树，可以**拖文件到 prompt**——自动 `@` 引用。

### 5. git worktree 隔离

高阶功能——**让 Claude 在独立 git 分支的副本上工作**，不污染你当前分支。

工作流程：
1. 创建 worktree（独立副本）
2. Claude 在这个副本里改东西
3. 满意 → merge 回主分支
4. 不满意 → 扔掉副本，主分支毫发无损

**比普通分支更隔离**——Claude 甚至不知道主分支存在。

## 概念对照表（终端 ↔ 桌面）

| 终端版 | 桌面应用对应 |
|-------|-----------|
| `claude` 启动 | 点图标启动 |
| `/exit` | 关闭会话 tab |
| 新会话 | 点 "+ New Session" |
| `@文件` | 拖文件 / 点 @ 按钮 |
| 看 Ctx% | 会话条显示 |
| `/model` | 会话顶部模型下拉 |
| `/clear` | 点 Clear 按钮 |
| `/rewind` | 点 Rewind 按钮 / 点消息左边的小箭头 |
| `/plan` | 模式切换按钮 |

## 本书所有概念在桌面应用里适用吗？

**完全适用**：
- ✅ 三层记忆（CLAUDE.md / MEMORY.md / 会话）
- ✅ 权限机制（弹窗可能是图形对话框，逻辑一样）
- ✅ 信任校准 L1-L4
- ✅ 模型与成本
- ✅ Skills / Commands / Subagents / Hooks / MCP

**界面不同但概念一样**：
- `@` 引用文件 → 拖拽或点按钮
- `/` 斜杠命令 → 大部分可用，或改用顶部按钮

## 一个建议的迁移节奏

**如果你已经用熟终端版**：
1. 装桌面版
2. 打开**同一个项目**
3. 做几件和终端版一样的事（读文件、改文件、审 diff）
4. 对比哪边你更顺
5. **不用强迫选一个**——两个可以并用

**如果你还没用过终端版**：
- 终端版和桌面版**任选其一**开始都行
- 本书教的所有概念适用
- 实际上很多人**桌面版起步、终端版收尾**（熟了之后发现终端更快）
