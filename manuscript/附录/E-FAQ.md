# 附录 E：FAQ（常见问题 10 问）

## 1. Claude 会偷看我的文件吗？

不会"偷"，但**你 @ 引用或让它 `!cat` 的文件内容**会上传到 Anthropic 服务器（HTTPS 加密传输），最多暂存 30 天后删除，**不用于训练**。

Claude 不会**主动**读你没让它读的文件——它只有工具权限，权限外动不了。

详见 Ch 11。

## 2. 用 Claude Code 大概多少钱一个月？

按使用强度粗略：
- **轻度**（每天 10-30 分钟）：$10-20 / 月
- **中度**（每天 1-2 小时）：$50-150 / 月
- **重度**（每天 3+ 小时）：$200+ / 月

推荐订阅 Claude Pro 起步。详见 Ch 15。

## 3. 它改坏我的文件了怎么办？

三种挽回：
1. **`/rewind`**：回退到改之前
2. **`Esc Esc`**：快速撤销最近一步
3. **git**：`git checkout <文件>` 恢复到上次 commit

最可靠是**重要任务前先 `!git commit -am "wip"`**——有回退锚点。

详见 Ch 9。

## 4. 我在公司用会不会违反数据政策？

**先查公司 AI 政策**。没有明文政策就发邮件问 IT / 合规。

**永远别发**：
- 密钥、token、密码
- 未脱敏的客户 / 员工信息
- NDA 覆盖的文档

合规场景 → 争取企业版（Zero Retention、私有部署）。详见 Ch 11。

## 5. 有哪些模型？怎么选？

三款主力：
- **Haiku 4.5**：快 + 便宜，简单查询
- **Sonnet 4.6**：中坚，日常默认
- **Opus 4.7**：最强 + 最贵，复杂推理

**新手建议**：默认 Sonnet、卡了切 Opus、简单事用 Haiku。`/model` 随时换。详见 Ch 15。

## 6. Claude 会记住我上次说的话吗？

**三层记忆**：
- **会话内**：记（到 `/clear` 或退出为止）
- **跨会话**：看情况——放在 **MEMORY.md**（Claude 自动记你偏好）或 **CLAUDE.md**（你手写的项目规则）的内容会记
- **完全无记忆**：每次新会话，你没明确存过的就不记

详见 Ch 13。

## 7. 一句话：CLAUDE.md 怎么写？

**不要用 `/init`**。手写，< 60 行：

- **WHAT**：项目是什么（1-2 句）
- **WHY**：关键决策为什么这么选
- **HOW**：3-5 条硬规则
- **Pointers**：指向详细文档的链接

发现 Claude 重复犯错时**再**补条目。详见 Ch 14。

## 8. Skill / Command / Subagent / Hook / MCP 怎么分？

- **Skill**：Claude 按需加载的任务手册
- **Command**：你主动敲 `/xxx` 触发
- **Subagent**：派独立小 Claude 干重活
- **Hook**：事件自动触发
- **MCP**：接外部工具（GDrive / Notion / DB）

**五者可组合使用**。详见 Part 5（Ch 20-24）。

## 9. 我可以和同事一起用吗？

可以。原则：
- **共享**：项目 `CLAUDE.md`、`.claude/commands/`、`.claude/skills/`、`.claude/agents/` → 进 git
- **私有**：`settings.local.json`、个人凭证、MCP 配置 → 不进 git
- **走 PR**：CLAUDE.md 改动都走 PR review

详见 Ch 25。

## 10. 读完书了，接下来干嘛？

**30 天挑战清单**：
- 第 1 周：稳固日常用法
- 第 2 周：管理上下文和 CLAUDE.md
- 第 3 周：用上扩展（至少一个 Skill / Command / MCP）
- 第 4 周：融入工作流 + 清理

**核心原则**：**选 1-2 个方向深入，不要追最新 / 囤工具 / 和人比**。详见 Ch 27。
