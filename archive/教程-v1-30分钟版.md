# Claude Code 快速上手教程

> 目标读者：已装好 Claude Code 的非技术背景用户
> 阅读 + 动手时间：约 30 分钟
> 撰写日期：2026-04

---

## 0. 开场（3 分钟）

### Claude Code 是什么

你可以把它想象成一个**住在你电脑里的实习生**——

- 你用中文（或任何语言）跟它说话，它听得懂
- 它能读你的文件、改你的文件、在你的电脑上跑命令
- 做任何可能影响到你电脑的事之前，它都会先问你一声

它**适合做的事**：整理文件、写文档、处理表格、把一堆资料总结成一篇、做点小自动化、帮你学新东西。

它**不适合做的事**：替你拿主意、做需要你本人创意和判断的工作。

### 准备工作环境

本教程全程用 **终端 + VS Code 并排** 的方式：

- **终端**：左半屏，负责和 Claude Code"说话"
- **VS Code**：右半屏，打开你的工作文件夹，实时看 Claude 改了啥

**怎么并排摆**：Mac 上把两个窗口分别拖到左右两半屏即可，或者用鼠标悬停在绿色最大化按钮上，选"窗口左移/右移"。

> 小贴士：一开始你可能觉得奇怪——为啥还要 VS Code？因为 Claude 改文件时，在终端里只能看到一段文字描述，在 VS Code 里你能**直接看到文件变成什么样**，心里踏实多了。

## 1. 你的第一次对话（3 分钟）

### 启动

1. 打开 **终端**（访达 → 应用程序 → 实用工具 → 终端）
2. 进入你想工作的文件夹，比如桌面上的一个练习文件夹：
   ```
   cd ~/Desktop/练习
   ```
3. 输入 `claude`，回车

你会看到一个输入框，光标在等你说话。

### 开始聊

直接打字就行，不需要特殊语法：

```
你：你好，简单介绍一下你自己，一句话就够。
Claude：你好！我是 Claude Code，能帮你读写文件、执行命令、完成各种电脑上的任务。
```

### 结束对话

按两次 `Ctrl + C`，或者输入 `/exit`。

### 动手小任务

启动 Claude Code，问它一句："**我现在在哪个文件夹？里面有什么？**" 看它怎么回答。

## 2. 让它帮你读写文件（5 分钟）

### @ 引用：告诉它看哪个文件

在对话里打 `@` 然后跟文件名，Claude 就能"看到"这个文件的内容。

```
你：@笔记.md 把里面所有"汽车"换成"车辆"
Claude：好的，我读了笔记.md，发现 3 处"汽车"，我替换一下 ...
```

Claude 改文件前，会先把**修改方案**（叫 diff）展示给你看，问你要不要改。你说"好"或"改吧"它才会真的动手。

### 切到 VS Code 看结果

改完后，切到右边的 VS Code，文件内容会自动刷新。你能直接看到最新版长啥样。

### 让它创建新文件

```
你：帮我在当前文件夹建一个 todo.md，里面写今天三件事：买菜、写周报、给妈打电话
Claude：好的，我要创建 todo.md，内容如下 ...（展示内容，等你确认）
```

### 动手小任务

1. 在桌面建一个文件夹叫 `练习`，里面随手建一个 `笔记.txt`，写几句话
2. 在终端 `cd ~/Desktop/练习`，启动 `claude`
3. 让它 **"@笔记.txt 帮我把内容翻译成英文，存成 notes-en.txt"**
4. 在 VS Code 里打开文件夹看看结果

## 3. 让它帮你跑命令（4 分钟）

### 它能在你的终端里干活

除了改文件，Claude 还能帮你在电脑上执行各种命令：列目录、新建文件夹、拷贝文件、压缩图片、搜索内容……

```
你：帮我把桌面上所有 png 图片列出来
Claude：我要运行 `ls ~/Desktop/*.png`，是否允许？
[允许一次] [总是允许] [拒绝]
```

### 权限提示——**读懂再选**

每当 Claude 想运行命令，都会弹出三个选项：

| 选项 | 什么时候选 |
|------|-----------|
| **允许一次** | 你看懂了这条命令在做什么，确认无害 |
| **总是允许** | 这类命令你完全放心（比如 `ls` 查看目录），下次不用再问 |
| **拒绝** | 看不懂、或者涉及删除/覆盖/联网 |

### 什么命令该停下来确认

- **`rm`**（删除）、**`mv`**（移动/覆盖）——可能丢文件
- **`sudo`** 开头——这是"管理员权限"，影响整个系统
- **`curl` / `wget` + 执行**——从网上下东西然后运行，风险高

**简单原则**：看不懂就问一句 **"这条命令会做什么？有没有风险？"** Claude 会解释给你听，解释完你再决定。

### 动手小任务

让 Claude **"帮我统计一下桌面上各种文件类型各有多少个"**，观察它给出什么命令、你该不该允许。

## 4. 常用快捷命令（3 分钟）

在对话框里输入 `/` 开头的命令，可以直接调出各种功能。最常用的这五个先记住：

| 命令 | 作用 | 什么时候用 |
|------|------|-----------|
| `/help` | 列出所有可用命令 | 忘了有啥命令时 |
| `/clear` | 清空当前对话 | 聊太久 Claude 变慢/变糊涂 |
| `/config` | 打开设置 | 改主题、模型、行为 |
| `/model` | 切换底层模型 | 想用更强的 Opus 或更快的 Haiku |
| `/init` | 生成项目说明书（下一节讲） | 新项目第一次用 |

### 小提醒：/clear 很重要

Claude 的"记忆"是有容量的，聊的越久它越容易变糊涂、变慢。**一个任务做完就 `/clear` 一下**，开始下一个任务，效果最好。

### 动手小任务

在对话框里打 `/help` 回车，浏览一下有哪些命令。看到感兴趣的记下名字，等会儿可以试。

## 5. 让它记住你的项目（3 分钟）

### CLAUDE.md 是什么

你可以在工作文件夹里放一个名为 `CLAUDE.md` 的文件，里面写：

- 这个项目/文件夹是做什么的
- 你的偏好（比如"回答用中文"、"写文档别超过 500 字"）
- 一些约定（比如"修改文件前先备份"）

每次在这个文件夹启动 Claude Code，它会**先读这个文件**，相当于先给它看一遍"岗位说明书"。

### 一个实例

```markdown
# 我的写作工作区

这个文件夹是我的文章草稿。

## 偏好
- 所有回复用中文
- 改文字时保留我的原始表达风格，不要过度润色
- 修改文章前先复制一份原文到 `备份/` 文件夹

## 禁忌
- 不要擅自删除文件
```

### 两种生成方法

**方法一**：让 Claude 帮你生成——在工作文件夹里打 `/init`，它会分析文件夹内容，自动起草一份给你
**方法二**：自己在 VS Code 里新建 `CLAUDE.md`，写几条偏好，保存

### 动手小任务

在你的练习文件夹里建一个 `CLAUDE.md`，写两条个人偏好。然后 `/clear` 清空对话，重新问 Claude "你知道我喜欢怎么被对待吗？" 看它是不是真的读到了。

## 6. 还能做什么（进阶概览，7 分钟）

下面四个是 Claude Code 的"进阶能力"。不要求你现在上手，只要**知道它们是什么、什么场景下你可以去查**，就达标了。

### Subagents（小分队）

**是什么**：专门干某类活的小助手，主 Claude 可以把任务分派给它们。

**生活化例子**：就像你开了个小工作室，雇了"专门整理发票的会计"、"专门校对错别字的编辑"。遇到特定任务，主 Claude 会召唤对应的小助手来处理，效率更高、也不会互相打扰。

**什么时候用**：任务复杂、需要分工，或者有一类活你经常做。

### MCP（外接工具）

**是什么**：让 Claude Code 连到它本机之外的服务——Google Drive、Slack、Notion、数据库……

**生活化例子**：Claude 本来只能操作你电脑里的文件。装个 Google Drive MCP 后，它就能读你云盘里的文档了；装个 Slack MCP 后，它能帮你总结昨天的群聊。

**什么时候用**：想让它跨应用干活，不光操作本地文件。

### Hooks（自动触发）

**是什么**：在某些事件发生时，自动执行一段动作。

**生活化例子**：你设一条规则"Claude 每次改完文件，就自动把原文件备份一份"——这样就不用每次嘱咐它。又比如"每次对话一结束，就自动把聊天记录存档"。

**什么时候用**：想让 Claude 的行为更规矩、省得每次交代同样的事。

### Skills（技能包）

**是什么**：预置好的"一键能力"，打一个 `/技能名` 就能调出完整的工作流。

**生活化例子**：`/init` 是个技能（一键生成 CLAUDE.md）、`/security-review` 是个技能（一键做安全检查）。你可以安装别人写好的技能，也可以自己写。

**什么时候用**：某个流程你经常要走一遍，就把它包成一个技能。

## 7. 下一步（2 分钟）

### 遇到问题先做这三件事

1. 在对话框打 `/help`，看内置命令能不能解决
2. 直接问 Claude："我想做 X，怎么办？" ——它经常自己就知道
3. 查官方文档：https://docs.claude.com/claude-code

### 三个最常见的坑

| 现象 | 原因 | 解决 |
|------|------|------|
| Claude 变糊涂、答非所问 | 对话太长，记忆满了 | `/clear` 清空重来 |
| Claude 总问权限很烦 | 每次都要单独允许 | 对安全的命令选"总是允许" |
| 改坏了文件 | 没备份 | 在 VS Code 里 `Cmd+Z` 撤销，或 git 回滚 |

### 学习建议

**不要光看教程**——打开你自己的真实任务（整理一次文件、写一份周报、分析一张表格），让 Claude 帮你做一遍。遇到卡点就问它，或回来翻这份教程对应的章节。

30 分钟到此结束。欢迎回头实践，祝你用得顺手。
